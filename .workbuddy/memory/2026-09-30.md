# 2026-09-30

## 将 v2 的健康检查与 Prometheus 指标功能合并到 jh 分支

把 v2 分支的 `pkg/health` 与 `pkg/metrics` 移植到 jh（v1）并接线。

- 新增 `health/` 包（探针 /health/live、/health/ready、/health/startup；MarkStarted/IsStarted/CheckDependencies）。依赖检查口径对齐 jh 的 checkAll()：mysql/mongodb/redis（jh 的 db 只有这三类有 Check()；v2 注释里写的 7 类并未在代码中实现，保持与 v2 一致）。
- 新增 `metrics/` 包（/metrics 端点 + Middleware() 自动记录 HTTP 计数/时延 + SetBuildInfo/SetPluginHealth/SetDependencyUp）。仅依赖 gin 与 prometheus。
- `app.go` 接线：App 增加 healthEnabled/healthMounted/metricsEnabled/metricsMounted 字段；baseRouter() 在所有 Use() 之前最早挂载探针与 /metrics；新增 EnableHealth/EnableMetrics/MarkHealthStarted；Run() 支持 go.health.autoStarted。
- 引入 `github.com/prometheus/client_golang v1.19.1`（go.mod/go.sum 已 tidy）。
- 顺带把退出信号通道改成带缓冲 `make(chan os.Signal, 1)`（v2 的做法，避免优雅关闭丢信号）。
- `application.example.yml` 补充 go.health / go.metrics 配置示例。
- 验证：`go build ./...` 通过，`go test ./health/... ./metrics/...` 通过。已提交到 jh 分支（commit d130653）。

注意：metrics Middleware 不会自动挂载，业务需自行 `app.Router.Use(metrics.Middleware())`；启用开关可用配置 `go.health.enabled`/`go.metrics.enabled` 或代码 `app.EnableHealth()/EnableMetrics()`。

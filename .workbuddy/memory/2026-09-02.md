# 2026-09-02 工作记录

## jh 分支新增三大能力（mgin 框架）

### 1. 单例限流中间件 `middleware/ratelimit`
- 三文件：`config.go`(yml 配置+规则匹配) / `limiter.go`(令牌桶/滑动窗口/并发三算法) / `ratelimit.go`(单例 Manager + Gin 中间件 + 空闲 GC)。
- 维度：global/ip/path/ip_path/header；算法：token_bucket/sliding_window/concurrency。
- 入口：`ratelimit.RateLimit()`(读 yml) / `ratelimit.RateLimitWith(rules...)` / 编程式 `ratelimit.Allow(key, rule)`。
- 启用开关：`go.config.used` 含 `ratelimit`，配置节点 `go.ratelimit`。

### 2. 类 xxl-job 定时任务管理器 `job`
- 文件：`model.go`(JobInfo/JobLog，跨库兼容不用方言类型) / `store.go`(MySQL→PostgreSQL→SQLite 优先级选库) / `handler.go`(执行器注册表+Context) / `scheduler.go`(调度核心) / `api.go`(Gin 路由组)。
- 调度类型：cron/fixed_rate/fixed_delay/once；阻塞策略 serial/discard/concurrent/cover；misfire do_nothing/fire_now；超时/重试。
- 表：`mgin_job_info`、`mgin_job_log`（前缀可配）。
- 管理接口：`job.RouterGroup(g)` → /job/list, /job/:id, POST/PUT /job, DELETE, /:id/start|stop|trigger, /job/handlers, /job/log。
- 手动触发：`job.GetManager().Trigger(id, param)`；注册执行器：`job.Register(name, func(*job.Context) error)`。
- 启用开关：`go.config.used` 含 `job`，配置节点 `go.job`；mgin.Init 阶段自动 Start，checkAll 探活，SafeExit 调 Stop。

### 3. S3 对象存储插件 `storage/s3`
- 基于 aws-sdk-go-v2（feature/s3/manager v1 稳定版，transfermanager 仍 v0.x 未 GA 故不用）。
- 文件：`config.go`(Config/BucketConfig) / `client.go`(S3 插件+MginPlugin 接口+Bucket 操作) / `util.go`(yaml 解析)。
- 操作：Upload/Download/Delete/Exists/List/Presign/PresignUpload/UploadMultipart；支持多 bucket(pathStyle 兼容 MinIO)。
- 入口：`s3.GetS3().Default()` / `.Get(name)`。
- 启用开关：`go.config.used` 含 `s3`，配置节点 `go.s3`；mgin.Init 读取 `go.s3` 字节 Init，UsePlugin 纳入生命周期。

### 集成要点（已写入 mgin.go）
- 新增 `initPlugins(m *mgin)`：used 含 `s3` 时 `m.UsePlugin("s3", s3.NewS3())`。
- Init 中 used 含 `job` 调 `job.Start()`。
- checkAll/SafeExit 已通过 `m.plugins` 循环覆盖 s3；job 单独判断字符串调用 Check/Stop。

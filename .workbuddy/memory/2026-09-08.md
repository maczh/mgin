
## pkg/registry & pkg/client 微服务注册/发现/注销优化
- 新增 `pkg/registry/cache.go`：`CachedRegistry` 装饰器，对 `GetServices` 做 TTL 缓存（默认 3s）+ 后台预热（1s）+ 并发去重(in-flight) + 注册中心抖动时降级复用旧实例列表；`registry.NewRegistry()` 默认包裹该层。配置项 `go.discovery.cacheTTL` / `cacheRefresh`。
- etcd：新增 `keepAliveLoop` 在租约通道关闭/续约失败时自动重注册（幂等 instanceId），`DeRegister` 用 context 取消协程并精准删 key（原 goroutine 泄漏 + fmt.Printf）。
- nacos：`DeRegister` 增加 worker==nil 保护（修复空指针 panic）、先停心跳再 DELETE；心跳连续失败≥3 次触发 `reRegister()`。
- consul：注册附加 TTL 健康检查(30s/1m 自动反注册) + 续活协程；记录 instanceID 精准反注册（原按 IP 重算易不匹配）。
- polaris：注册时记录 serviceID，DeRegister 优先使用（缓存兜底）。
- client：`selectHostByLB` 全部实例熔断时快速失败，不再回退 v1 随机选实例。
- 验证：go build ./...、go vet 通过；新增缓存单测 `go test ./pkg/registry/` 全过；client 测试通过。etcd/consul/polaris 既有测试需真实注册中心（环境无 server），非本次引入。

## jh 分支：mgin/registry & mgin/client 同样的优化（适配精简接口）
- jh 分支为扁平布局（模块 `github.com/maczh/mgin`，无 `pkg/`），`RegistryClient` 接口为 `Register/GetServiceURL(servicename,group...)(string,string)/DeRegister`，**无** `GetServices`/负载均衡/熔断。
- 新增 `registry/cache.go`：`CachedRegistry` 装饰器包裹 `GetServiceURL`，TTL 缓存(3s)+后台刷新热key(1s)+singleflight 并发去重+降级复用旧实例（注册中心抖动时）；空结果不缓存。`NewRegistry()` 默认包裹各后端。配置 `go.discovery.cacheTTL`/`cacheRefresh`。
  - 与 pkg/ 版差异：pkg/ 缓存的是实例列表+调用端LB；jh 缓存的是 GetServiceURL 返回的单一实例地址，跨 TTL 窗口由后台刷新轮换。
- etcd：`keepAliveLoop` 续约通道关闭/失败自动 `reRegister`（幂等），`DeRegister` 用 ctx cancel 停协程+精确删 registeredKey（移除 fmt.Printf/goroutine 泄漏）。
- nacos：心跳连续失败≥3 次触发 `reRegister()`；`DeRegister` 先 close(quit) 停心跳再 DELETE（带重复 close 保护）。
- consul：注册加 TTL 健康检查(30s)+`passTTL` 续活(25s)，记录 instanceID，`DeRegister` 优先用存储 ID 并停协程，增加 client==nil 保护。
- polaris：注册时存 instanceId 到结构体，`DeRegister` 优先使用（缓存兜底）。
- 验证：go build ./...、go vet 通过；`registry/cache_test.go` 4 个用例通过（命中/降级/空不缓存/singleflight）；各后端测试二进制编译通过。配置示例写入 `application.example.yml` 的 `discovery` 段。
- 注意：`go build ./...` 曾因 TMPDIR/$WORK 临时盘满报 "no space left on device"（磁盘本身有 146G 余量），重设 TMPDIR=/home/macro/tmp 后通过；go build cache 已 `go clean -cache`。

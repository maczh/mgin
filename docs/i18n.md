# 内置 i18n 数据库字典

通过 `mgin.NewApp(..., true)` 或 `go.i18n.enabled: true` 启用。框架在数据库初始化后创建 `<go.application.name>_i18n` 字典表，初始化失败会终止启动。应用名支持字母、数字、点、下划线、短横线，最多 59 个 ASCII 字符，表名中的点按字面值处理。

存储选择：

1. `go.config.used` 包含 `mysql`：复用应用 MySQL 连接。多库时优先使用 `go.i18n.dbName`，未指定则取第一个可用连接。MySQL 连接失败直接返回错误。
2. 未配置 MySQL、但显式启用了 `sqlite`：复用应用 SQLite 连接。
3. 其余情况：自动打开独立 SQLite 文件，默认位于应用配置目录的 `<app.name>_i18n.db`，无需在 `used` 中添加 SQLite。

本模块不处理 Postgres。`mgin.SafeExit()` 会关闭 i18n 自己打开的 SQLite，复用的数据库仍由框架统一关闭。

```yaml
go:
  application:
    name: myapp
  i18n:
    enabled: true
    default: zh-cn
    dbName: ""               # MySQL 多库模式下选择连接名
    sqlite: ""               # 独立 SQLite 路径；相对路径基于应用配置文件目录
    api:
      enabled: true          # 自动挂载 /i18n 管理接口，默认 false
```

每条记录包含 `messageId`、`language`、`text`、`createdAt`、`updatedAt`。`messageId + language` 为联合主键；语言统一小写，`zh_CN` 转为 `zh-cn`。消息 ID 最多 191 个字符，语言标签最多 35 个字符，非空译文最多 65535 UTF-8 字节。MySQL 字典表使用 utf8mb4，消息 ID 区分大小写。

## CRUD 接口

接口保持 HTTP 200 的框架约定，普通响应为 `vo.Response`，列表为 `vo.ResponsePage`。`code=1` 成功；400 参数错误，404 条目不存在，409 联合主键重复，500 存储失败，503 字典未初始化。

| 方法 | 路径 | 参数 / 行为 |
| --- | --- | --- |
| POST | `/i18n` | JSON 新增条目 |
| GET | `/i18n?messageId=hello&language=en` | 精确读取条目，不执行语言回退 |
| PUT | `/i18n` | JSON 更新指定消息与语言的译文，不存在时返回 404 |
| DELETE | `/i18n?messageId=hello&language=en` | 删除指定条目 |
| GET | `/i18n/list?page=1&pageSize=20` | 分页，支持 `messageId`、`language` 精确筛选；pageSize 最大 100 |

新增或修改请求：

```json
{"messageId":"welcome","language":"en","text":"Welcome {}"}
```

列表返回 `data.list/total/page/pageSize`。时间字段由服务端维护。特殊字符消息 ID 通过 URL query 编码传递。

也可关闭自动挂载，将路由绑定到应用自己的管理路由组：

```go
admin := app.Router.Group("/admin")
admin.Use(authMiddleware)
i18n.RouterGroup(admin.Group("/i18n"))
```

程序内通过 `i18n.GetStore()` 获取存储，使用带 `context.Context` 的 `Create`、`Get`、`Update`、`Delete`、`List`、`Translate` 方法；`NewStore(conn, appName)` 支持在现有 GORM 连接上创建独立字典。

## 翻译与迁移

`i18n.String`、`Format`、`Error/ErrorT`、`Success` 等入口保留。请求语言仍由 `X-Lang` 头指定，未指定时使用 `go.i18n.default`（默认 `zh-cn`）。请求结束清除当前请求的语言上下文。

翻译按“请求语言 → 默认语言 → 原消息 ID”回退。翻译直接查询数据库，单次调用最多等待 3 秒；没有本地字典缓存、版本检查或刷新协程，CRUD 修改提交后即可被各实例的后续查询读取。存储异常时 `String` 返回原消息 ID，需要区分错误的调用方可使用 `Store.Translate(ctx, ...)`。

已删除 x-lang 微服务地址、版本查询、公共 default 应用字典合并和远程字典拉取逻辑；`go.xlang.*` 配置不再使用。旧字典不会自动迁移，请通过 CRUD 或程序接口导入。`GetXLangString` 保留为本地 `GetString` 的兼容别名。

#### `MySQLTx`

```go
func MySQLTx[T any](ctx context.Context, fn func(tx *gorm.DB) (T, error), dbName ...string) (T, error)
```

MySQLTx runs fn atomically on one MySQL connection. DAOs used by fn must be
bound with WithTx(tx); otherwise they intentionally use their normal pool.

#### `TransactionOn`

```go
func TransactionOn[T any](ctx context.Context, conn *gorm.DB, fn func(tx *gorm.DB) (T, error)) (T, error)
```

TransactionOn executes a callback and rolls back on every callback error.

### 类型

#### `Dao`

```go
type Dao[E any] interface
```

Dao[E] 是 mgin v2 扩展后的泛型 DAO 接口。

v1 时代仅包含 Insert(*E) error 一个方法，v2 扩展为与 db/dao/mysql.go、postgres.go、
clickhouse.go、mgo.go 等具体实现对齐的最小方法集。已有具体实现（MySQLDao 等）的方法
集合已经超过这个接口，因此把它们"补齐签名"以满足本接口即可。

注意：v2 Dao 接口仍然保持小而精，避免在接口里强加大量可选方法。具体实现可以
拥有接口之外的扩展方法（如 MySQLDao.Debug()、MySQLDao.WithContext()），
业务需要时直接断言到具体类型调用。

| 方法/内嵌 | 签名 |
|-----------|------|
| `Insert` | func(entity *E) error |
| `Where` | func(query interface{}, args ...interface{}) *gorm.DB |
| `Find` | func(query interface{}, args ...interface{}) ([]E, error) |
| `FindById` | func(id interface{}) (E, error) |
| `Update` | func(entity *E) error |
| `Delete` | func(entity *E) error |
| `Count` | func() (int64, error) |
